## README scope

- Write the README for someone deciding whether and how to use the project.
  Cover its purpose, requirements, setup, and practical usage examples.
- Update the README when a change affects what users need to know or do.
  An internal refactor alone does not need a README entry.
- Keep implementation details, design rationale, and agent workflows out
  of the README. When they need documenting, use the project's existing
  contributor docs or AGENTS.md, as appropriate.
